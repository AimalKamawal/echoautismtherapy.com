To publish on GitHub Pages:
1. Upload index.html and the entire images folder to the root of your repository.
2. In GitHub, open Settings -> Pages.
3. Choose Deploy from a branch, select your main branch and /(root), then Save.
4. Wait for GitHub Pages to publish the site.

The website intentionally has no intake form or intake CTA. Phone and email contact options remain.
Please verify service details, insurance participation, and all contact information before publishing.
